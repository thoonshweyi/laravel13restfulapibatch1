=>Passport Install
    (i) Install
        https://laravel.com > Docs (menu) > Packages (left side bar) > Passport (left side bar)
        https://laravel.com/framework/docs/passport
        
        php artisan install:api --passport

            Note: this command will arrange
                (1) 0Auth migration
                (2) 0Auth tables
                (3) Token signing keys

                Check: you can check 
                1. database > migrations
                2. storage > (0auth-private.key and 0auth-public.kdy)

                *error
                php artisan boost:update --ansi

                # while installing we may have some error like boost install. but we don't need to install boost (optional)
                php artsian boost:install
                php artisan boost:update

                    boosts features (boots for laravel's performance optimization package)
                    (i) AI Guideline
                    (ii) Agent Skills
                    (iii) Boost MCP (Modal Context Protocol) Server Configuration
