=> REST API
    REST = Representational State Transfer
    Web Service Architectral Style. It's mean following the principle and constraints of REST.

=> RESTful API
    A RESTful API is a communication system built between the Frontend and Backend that uses HTTP  to perfor
    CRUD (Create, Read, Update, Delete) on data.
------------------------------------------------------
=> HTTP Status Codes

Code    Name                    When                        Eg
200     OK                      body(option)                Product List
201     Created                 create new resource /Post   create new Product
204     No Content              Deleted success, no body    delete Product
400     Bad Request             Syntax/Format               JSON Parse Error        // သွားတောင်းတာတစ်ခု ပေးလိုက်တာတစ်ခု
401     Unauthorized            Login/Token                 No Token/ Wrong Token   
403     Forbidden               No Permission               User try to read Admin Page
404     Not Found               No Resource                 try to read Invalid Product ID
429     Too Many Requests       Rate Limit                  Over limit              // api ခေါ်တဲ့ limit ကျော်သွားတာ, incorrect login apptempts 
500     Internal Server Error   Server Error                Database Crash
-----------------------------------
